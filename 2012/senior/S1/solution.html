2012 S1 · Don't pass me the ball!

2012 / senior / S1

官方题目PDFDMOJ

题目在问什么

进球者的号码 J 已固定。四名触球球员中，前三人的号码必须严格递增且都小于 J；求有多少种合法组合。

考查知识点

  • 严格递增表示每个后面的数都比前面的数大，例如 1、3、4、6。号码不能重复，前三人的号码只能从 1 到 J−1 中选择。
  • 组合是在若干不同对象中选出一组，先不考虑排列次序。例如从 1、2、3、4 中选三人，只有 {1,2,3}、{1,2,4}、{1,3,4}、{2,3,4} 四组。
  • 每组三个号码都有唯一的递增排列。因此无需枚举传球顺序，只需计算“从 J−1 人中选三人”的组合数。Python 标准库的 comb(n, 3) 正好计算这个数；当 n<3 时结果是 0。
  • 组合数公式：从 n 人中有顺序地选三人有 n(n−1)(n−2) 种，但同一组三人在这份计数中出现了 3×2×1=6 次，所以不计顺序时要除以 6。

一步一步想

  1. 读取进球者的号码 J；他是第四名球员，前三人必须从比他号码小的 J−1 人中选出。
  2. 用 comb(J−1, 3) 计算三人组合数。J≤3 时没有足够的前三人，函数会得到 0。
  3. 输出这个整数。每个组合按号码升序排列后恰好对应一种合法进球过程。

用例子走一遍

若 J=5，可选前三人的号码是 1、2、3、4。四组为 {1,2,3}、{1,2,4}、{1,3,4}、{2,3,4}；各自按升序传球给 5，所以答案是 4，也等于 4×3×2÷6。

样例 J=4 时只能选 1、2、3，答案是 1；J=2 时比 2 小的号码只有 1，无法选出三人，答案是 0。样例 J=90 时，答案为 89×88×87÷6=113564。

为什么这样做是对的

任何合法进球过程都以固定的 J 结束，前三人的号码是 1 到 J−1 中三个不同的数，因此它确定了一个三人组合。反过来，从这些号码中任选三个不同的数，将它们按升序排列，再接上 J，就得到合法的严格递增四人过程。每个组合的升序排列唯一，所以不同组合不会对应同一过程，也没有合法过程遗漏。由此，合法过程与三人组合一一对应，comb(J−1, 3) 就是答案。候选人数不足三人时，两者都为零。

运行时间与内存

本题固定只选三人，且 J≤99；计算只需固定次数的整数运算，时间和额外空间均为 O(1)，即不需要随人数增长的循环或列表。最大答案是 comb(98,3)=152096，整数很小，计算公式时也不需要浮点数。

容易出错的地方

  • 四名球员包含已固定的进球者，所以选前三人，不是再选四人。
  • 前三人的号码必须小于 J，候选人数为 J−1；不能把进球者再选一次。
  • 递增规则已决定每组的唯一顺序；若把所有排列都算进去，会多算六倍。
  • J=1、2、3 时答案为 0。不要让一个要求人数足够的手写阶乘公式在这些输入上出错。

Python 3 解法

solution.py
from math import comb

jersey = int(input())
print(comb(jersey - 1, 3))

Problem statement (English)
Problem S1: Don’t pass me the ball!
Problem Description
A CCC soccer game operates under slightly different soccer rules. A goal is only counted if the
4 players, in order, who touched the ball prior to the goal have jersey numbers that are in strictly
increasing numeric order with the highest number being the goal scorer.
Players have jerseys numbered from 1 to 99 (and each jersey number is worn by exactly one
player).
Given a jersey number of the goal scorer, indicate how many possible combinations of players can
produce a valid goal.

Input Specification
The input will be the positive integer J (1 ≤ J ≤ 99), which is the jersey number of the goal
scorer.

Output Specification
The output will be one line containing the number of possible scoring combinations that could
have J as the goal scoring jersey number.

Sample Input 1
4

Output for Sample Input 1
1

Sample Input 2
2

Output for Sample Input 2
0

Sample Input 3
90

Output for Sample Input 3
113564

Official problemPDFDMOJ

What are we asked to do?

The scorer's jersey J is fixed. Among the four players who touch the ball, the first three must have strictly increasing numbers below J. Count the valid groups.

Knowledge and skills

  • Strictly increasing means each number is larger than the previous one, as in 1, 3, 4, 6. Numbers cannot repeat, so the first three jerseys must be selected from 1 through J−1.
  • A combination selects a group of distinct objects without counting different orders. For example, choosing three jerseys from 1, 2, 3, 4 gives just four groups: {1,2,3}, {1,2,4}, {1,3,4}, and {2,3,4}.
  • Every group of three numbers has exactly one increasing order. Therefore we count combinations of three from J−1 players instead of enumerating passing orders. The Python standard-library function comb(n, 3) does exactly this, returning 0 when n<3.
  • To derive the formula, choosing three players in order gives n(n−1)(n−2) choices. Each group appears in 3×2×1=6 different orders, so the number of groups is this product divided by 6.

Think step by step

  1. Read the scorer's jersey J. The scorer is the fourth player, leaving J−1 smaller jerseys available for the first three.
  2. Compute comb(J−1, 3). If J≤3, there are too few available players and the function returns 0.
  3. Print the integer. Sorting each chosen group increasingly gives exactly one valid sequence ending at J.

Walk through an example

For J=5, the available jerseys are 1, 2, 3, 4. The groups are {1,2,3}, {1,2,4}, {1,3,4}, and {2,3,4}. Each group passes in increasing order and then to 5, giving 4 possibilities, also calculated as 4×3×2÷6.

For sample J=4, only the group 1,2,3 works, so the answer is 1. For J=2, only jersey 1 is smaller and we cannot choose three players, so the answer is 0. For sample J=90, the result is 89×88×87÷6=113564.

Why does this work?

Every valid sequence ends with the fixed scorer J. Its first three jerseys are three distinct numbers from 1 through J−1, so the sequence determines a combination of three. Conversely, selecting any three distinct numbers from that range, sorting them increasingly, and appending J produces a valid four-player sequence. A group has only one increasing order, so different groups cannot produce the same sequence and no valid sequence is missed. This one-to-one correspondence proves that comb(J−1, 3) counts exactly the valid sequences. When fewer than three jerseys are available, both counts are zero.

Time and memory

We always choose exactly three players, and J≤99, so only a fixed number of integer operations is needed. Time and extra space are O(1): there is no loop or list that grows with the player count. The largest answer is comb(98,3)=152096. These are small integers, and no floating-point division is needed.

Common mistakes

  • The four players include the fixed scorer, so choose three additional players, not four.
  • Only jerseys below J are eligible: there are J−1 candidates, and the scorer cannot be selected again.
  • The increasing rule fixes each group's order. Counting every permutation would overcount by a factor of six.
  • J=1, 2, or 3 must produce 0. A hand-written factorial formula that assumes enough players could fail on these inputs.
