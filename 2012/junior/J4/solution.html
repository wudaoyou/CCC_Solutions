2012 / junior / J4

官方题目PDFDMOJ

题目在问什么

每个密文字母使用它在单词中的位置 P 计算位移 S = 3P + K。解码时从密文字母向后移动 S 位，并在字母表两端循环。

考查知识点

  • 字符串：由按顺序排列的字符组成，处理时不能改变字母的顺序。
  • 字符编号：ord(letter) 取得字符对应的整数；减去 ord("A") 就让 A 到 Z 对应 0 到 25。chr 把整数转回字符。
  • 取模循环：% 26 求除以 26 的余数，把超出字母表范围的编号绕回 0 到 25。

一步一步想

  1. 读取整数 K 和大写密文。位置 P 从 1 开始计数，所以第一个字母用 P = 1，第二个用 P = 2。
  2. 把字母 A 到 Z 看成编号 0 到 25。向前移动一位并越过 Z 时会回到 A；% 26 表示把结果绕回这 26 个编号内。
  3. 对每个字母计算题目规定的位移 S = 3P + K。密文是向前移动得到的，所以解码要减去 S，再用 % 26 循环回 0 到 25。
  4. 把每个得到的编号换回大写字母，并按原顺序连接后输出。

用例子走一遍

样例 1 中 K = 3，密文是 FXAB。第一个密文字母 F 的位置 P = 1，位移是 3 × 1 + 3 = 6。F 编号为 5；(5 - 6) % 26 = 25，对应 Z。对四个字母逐个解码后得到 ZOOM。

为什么这样做是对的

处理位置 P 时，程序使用与加密规则完全相同的位移 3P + K，并从密文字母编号中减去它。加密把原编号加上这个位移并对 26 取余；解码再减去同一位移并对 26 取余，因此会回到原编号。每个位置都独立恢复出对应的原字母，且程序按输入顺序连接所有字母，所以输出正好是原单词。

运行时间与内存

令 n 为单词的字母数。程序对每个字母只做固定次数的计算，所以时间是 O(n)。O(n) 表示字母数加倍时，工作量也大约加倍。输入单词和解码结果各占 O(n) 空间；除此之外只用固定数量的变量。

容易出错的地方

  • 位置 P 从 1 开始，不是从 0 开始。
  • 解码要减去位移；加上位移是加密操作。
  • 位移对每个位置都不同，必须使用当前字母自己的 P。
  • 减法可能得到负数；对 26 取模会正确地绕回 Z 附近。
  • 输入是一个不含空格的大写单词，最多 20 个字母。

Python 3 解法

solution.py
import sys


def main():
    key, message = sys.stdin.read().split()
    key = int(key)
    print("".join(
        chr((ord(letter) - ord("A") - (3 * position + key)) % 26 + ord("A"))
        for position, letter in enumerate(message, start=1)
    ))


if __name__ == "__main__":
    main()

Problem statement (English)
Problem J4: Big Bang Secrets
Problem Description
Sheldon and Leonard are physicists who are fixated on the BIG BANG theory. In order to exchange
secret insights they have devised a code that encodes UPPERCASE words by shifting their letters
forward.
Shifting a letter by S positions means to go forward S letters in the alphabet. For example, shifting
B by S = 3 positions gives E. However, sometimes this makes us go past Z, the last letter of
the alphabet. Whenever this happens we wrap around, treating A as the letter that follows Z. For
example, shifting Z by S = 2 positions gives B.
Sheldon and Leonard’s code depends on a parameter K and also varies depending on the position
of each letter in the word. For the letter at position P , they use the shift value of S = 3P + K.
For example, here is how ZOOM is encoded when K = 3. The first letter Z has a shift value
of S = 3 × 1 + 3 = 6; it wraps around and becomes the letter F. The second letter, O, has
S = 3 × 2 + 3 = 9 and becomes X. The last two letters become A and B. So Sheldon sends
Leonard the secret message: FXAB
Write a program for Leonard that will decode messages sent by Sheldon.

Input Specification
The input will be two lines. The first line will contain the positive integer K (K < 10), which
is used to compute the shift value. The second line of input will be the word, which will be a
sequence of uppercase characters of length at most 20.

Output Specification
The output will be the decoded word of uppercase letters.

Sample Input 1
3
FXAB

Output for Sample Input 1
ZOOM

Sample Input 2
5
JTUSUKG

Output for Sample Input 2
BIGBANG

Official problemPDFDMOJ

What are we asked to do?

Each encrypted letter uses its position P in the word to calculate a shift S = 3P + K. To decode it, move backward by S letters and wrap around the alphabet.

Knowledge and skills

  • Strings: ordered sequences of characters; preserve the letter order while decoding.
  • Character numbers: ord(letter) gives a character code. Subtracting ord("A") maps A through Z to 0 through 25; chr converts a code back to a character.
  • Modular wraparound: % 26 gives the remainder after division by 26, bringing a number back into 0 through 25.

Think step by step

  1. Read the integer K and the uppercase encrypted word. Positions P start at 1, so the first letter uses P = 1 and the second uses P = 2.
  2. Treat A through Z as numbers 0 through 25. Moving forward past Z returns to A; % 26 wraps a result back into these 26 numbers.
  3. For each letter, calculate the shift S = 3P + K from the statement. Encryption moved forward, so decoding subtracts S from the encrypted letter's number, then uses % 26 to wrap into 0 through 25.
  4. Convert each resulting number back to an uppercase letter, join the letters in their original order, and print the word.

Walk through an example

In sample 1, K = 3 and the encrypted word is FXAB. For the first encrypted letter F, P = 1, so the shift is 3 × 1 + 3 = 6. F has number 5; (5 - 6) % 26 = 25, which is Z. Decoding all four letters gives ZOOM.

Why does this work?

At position P, the program uses the same shift 3P + K as the encryption rule and subtracts it from the encrypted letter's number. Encryption adds this shift and takes the remainder after division by 26; decoding subtracts the same shift and takes the remainder by 26, returning to the original number. Each position therefore recovers its original letter. The program joins the letters in input order, so its output is exactly the original word.

Time and memory

Let n be the number of letters in the word. The program does a fixed amount of work for each letter, so the time is O(n). O(n) means that doubling the number of letters roughly doubles the work. The input word and decoded result each use O(n) space; only a fixed number of variables are used beyond them.

Common mistakes

  • Positions P start at 1, not 0.
  • Decoding subtracts the shift; adding it performs encryption.
  • The shift changes at each position, so use the current letter's P.
  • Subtraction can produce a negative number; taking the remainder by 26 wraps it back near Z correctly.
  • The input is one uppercase word without spaces and has at most 20 letters.
