2012 / junior / J2

官方题目PDFDMOJ

题目在问什么

根据四个连续水深读数的顺序，判断鱼探仪应报告上升、下降、深度不变，还是没有鱼。

考查知识点

  • 严格递增：每个读数都比前一个大，例如 2、4、5、9；相等不算增加。
  • 严格递减：每个读数都比前一个小，例如 9、7、4、1。
  • 连续比较：只要四个读数中有一对不符合方向，整个序列就不是严格单调的。

一步一步想

  1. 读取四个水深数值 a、b、c、d。
  2. 检查 a < b < c < d。如果成立，四次读数都严格上升，输出 Fish Rising。
  3. 否则检查 a > b > c > d。如果成立，输出 Fish Diving；再检查四个数是否全部相等，如果相等就输出 Fish At Constant Depth。
  4. 如果以上条件都不成立，至少有一处方向改变或相邻数值相等，输出 No Fish。

用例子走一遍

读数 1、10、12、13 满足 1 < 10、10 < 12、12 < 13，因此每一步都变大，输出 Fish Rising。

为什么这样做是对的

严格递增判断同时要求第一数小于第二数、第二数小于第三数、第三数小于第四数，所以它恰好识别题目定义的上升序列。严格递减判断以同样方式检查每一步都变小；相等判断要求四个值全部相同。若三种情况都不成立，读数就属于题目定义的 No Fish。

运行时间与内存

只比较四个读数中的固定几对，因此运行时间是 O(1)。O(1) 表示读数的大小不会增加比较次数。额外空间也是 O(1)，因为程序只保存四个整数。

容易出错的地方

  • 上升和下降必须是严格的；例如 1、2、2、3 不是 Fish Rising。
  • 全部相等时输出 Fish At Constant Depth，注意完整的输出文字。
  • 不要只比较第一个和最后一个；中间任意一步都必须符合相同方向。

Python 3 解法

solution.py
import sys

a, b, c, d = map(int, sys.stdin.read().split())

if a < b < c < d:
    print("Fish Rising")
elif a > b > c > d:
    print("Fish Diving")
elif a == b == c == d:
    print("Fish At Constant Depth")
else:
    print("No Fish")

Problem statement (English)
Problem J2: Sounds fishy!
Problem Description
A fish-finder is a device used by anglers to find fish in a lake. If the fish-finder finds a fish, it will
sound an alarm. It uses depth readings to determine whether to sound an alarm. For our purposes,
the fish-finder will decide that a fish is swimming past if:

   • there are four consecutive depth readings which form a strictly increasing sequence (such as
     3 4 7 9) (which we will call “Fish Rising”), or
   • there are four consecutive depth readings which form a strictly decreasing sequence (such as
     9 6 5 2) (which we will call “Fish Diving”), or
   • there are four consecutive depth readings which are identical (which we will call “Constant
     Depth”).
All other readings will be considered random noise or debris, which we will call “No Fish.”
Your task is to read a sequence of depth readings and determine if the alarm will sound.

Input Specification
The input will be four positive integers, representing the depth readings. Each integer will be on
its own line of input.

Output Specification
The output is one of four possibilities. If the depth readings are increasing, then the output
should be Fish Rising. If the depth readings are decreasing, then the output should be Fish
Diving. If the depth readings are identical, then the output should be Fish At Constant
Depth. Otherwise, the output should be No Fish.

Sample Input 1
30
10
20
20

Output for Sample Input 1
No Fish

Sample Input 2
1
10
12
13

Output for Sample Input 2
Fish Rising

Official problemPDFDMOJ

What are we asked to do?

Use the order of four consecutive depth readings to decide whether the fish-finder reports rising, diving, constant depth, or no fish.

Knowledge and skills

  • Strictly increasing: every reading is greater than the one before it, such as 2, 4, 5, 9; equality does not count as an increase.
  • Strictly decreasing: every reading is less than the one before it, such as 9, 7, 4, 1.
  • Consecutive comparisons: if even one pair does not follow the direction, the whole sequence is not strictly monotone.

Think step by step

  1. Read the four depth values a, b, c, and d.
  2. Check a < b < c < d. If true, all four readings rise strictly, so print Fish Rising.
  3. Otherwise, check a > b > c > d. If true, print Fish Diving. Then check whether all four values are equal; if they are, print Fish At Constant Depth.
  4. If none of these conditions is true, some direction changes or an adjacent pair is equal, so print No Fish.

Walk through an example

The readings 1, 10, 12, 13 satisfy 1 < 10, 10 < 12, and 12 < 13. Every step increases, so the output is Fish Rising.

Why does this work?

The strictly increasing check requires the first value to be less than the second, the second less than the third, and the third less than the fourth. That is exactly the rising rule in the statement. The decreasing check similarly requires every step to get smaller, while the constant check requires all four values to match. If none applies, the readings meet the definition of No Fish.

Time and memory

The program compares only a fixed number of pairs among four readings, so the running time is O(1). O(1) means the sizes of the readings do not add more comparisons. Extra space is also O(1), because only four integers are stored.

Common mistakes

  • Rising and diving are strict; for example, 1, 2, 2, 3 is not Fish Rising.
  • For four equal readings, print Fish At Constant Depth with the complete wording.
  • Do not compare only the first and last readings; every middle step must follow the same direction.
