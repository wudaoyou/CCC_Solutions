2014 J1 · Triangle Times

2014 / junior / J1

官方题目PDFDMOJ

题目在问什么

先检查三个角的和是否为 180 度，再根据相等角的数量判断三角形类型。

考查知识点

  • 三角形内角和：三角形的三个内角相加必须是 180 度。
  • 相等关系：三个角全相等是等边三角形（Equilateral）；恰有一对相等是等腰三角形（Isosceles）；三个角各不相同是不等边三角形（Scalene）。
  • 优先判断：角的和不正确时，输入不是有效三角形，因此要先输出 Error。

一步一步想

  1. 读取三个角 a、b、c，并计算 total = a + b + c。
  2. 如果 total 不等于 180，输出 Error 并结束判断。
  3. 否则，如果三个角都相等，输出 Equilateral。
  4. 否则，如果任意一对角相等，输出 Isosceles；如果没有任何一对相等，输出 Scalene。

用例子走一遍

50、50、50 虽然三个角相等，但总和只有 150，所以输出 Error。40、70、70 的总和是 180，且只有一对角相等，所以输出 Isosceles。

为什么这样做是对的

若三个角的和不等于 180，程序立即输出 Error，符合三角形内角和规则。其余输入满足角和规则：三个角全相等时输出 Equilateral；否则若有一对相等，正好是 Isosceles；如果没有相等角，就是 Scalene。这些分支互不重叠并覆盖所有输入，因此只输出正确的一类。

运行时间与内存

程序只读取并比较三个数，工作量不随角度大小改变，所以时间是 O(1)。O(1) 表示固定数量的运算。额外空间也是 O(1)，因为只保存三个角和它们的总和。

容易出错的地方

  • 先判断总和；例如三个相等的 50 度角仍然要输出 Error。
  • 有效的三个相等角只能都是 60 度；这类应输出 Equilateral，而不是 Isosceles。
  • 输出只能是题目指定的 Equilateral、Isosceles、Scalene 或 Error。

Python 3 解法

solution.py
import sys

a, b, c = map(int, sys.stdin.read().split())
total = a + b + c

if total != 180:
    print("Error")
elif a == b == c:
    print("Equilateral")
elif a == b or a == c or b == c:
    print("Isosceles")
else:
    print("Scalene")

官方题目

官方题目原文为英文；图表和原版排版请看 PDF。

Problem statement (English)
Problem J1: Triangle Times
Problem Description
You have trouble remembering which type of triangle is which. You write a program to help.
Your program reads in three angles (in degrees).

   • If all three angles are 60, output Equilateral.

   • If the three angles add up to 180 and exactly two of the angles are the same, output Isosceles.

   • If the three angles add up to 180 and no two angles are the same, output Scalene.

   • If the three angles do not add up to 180, output Error.


Input Specification
The input consists of three integers, each on a separate line.
Each integer will be greater than 0 and less than 180.

Output Specification
Exactly one of Equilateral, Isosceles, Scalene or Error will be printed on one line.

Sample Input 1
60
70
50

Output for Sample Input 1
Scalene

Sample Input 2
60
75
55

Output for Sample Input 2
Error

Official problemPDFDMOJ

What are we asked to do?

First check whether the three angles add to 180 degrees, then classify the triangle by which angles are equal.

Knowledge and skills

  • Triangle angle sum: the three interior angles of a triangle must add to 180 degrees.
  • Equal angles: three equal angles mean Equilateral; exactly one equal pair means Isosceles; no equal pair means Scalene.
  • Check order: an incorrect angle sum is not a valid triangle, so print Error before classifying equal angles.

Think step by step

  1. Read the three angles a, b, and c, then calculate total = a + b + c.
  2. If total is not 180, print Error and stop the classification.
  3. Otherwise, if all three angles are equal, print Equilateral.
  4. Otherwise, if any pair is equal, print Isosceles. If no pair is equal, print Scalene.

Walk through an example

The angles 50, 50, 50 are equal, but their sum is only 150, so the answer is Error. The angles 40, 70, 70 sum to 180 and have exactly one equal pair, so the answer is Isosceles.

Why does this work?

If the angles do not add to 180, the program prints Error as required by the triangle angle-sum rule. Every remaining input has a valid sum: three equal angles are classified as Equilateral; otherwise, an equal pair makes the triangle Isosceles; with no equal pair it is Scalene. These cases do not overlap and cover every input, so exactly the correct classification is printed.

Time and memory

The program reads and compares only three numbers, so its running time is O(1). O(1) means a fixed number of operations. Extra space is also O(1), since only the three angles and their sum are stored.

Common mistakes

  • Check the sum first; three equal 50-degree angles still require the answer Error.
  • A valid triangle with three equal angles must have three 60-degree angles; classify it as Equilateral, not Isosceles.
  • Print exactly one of Equilateral, Isosceles, Scalene, or Error.
