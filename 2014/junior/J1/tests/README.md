官方 Junior 测试包已随仓库提供，包含 6 组输入输出；这些 `.in` 和 `.out` 文件保持原样。独立边界检查覆盖角度和为 180、和不为 180、三角形全等角、恰有一对相等，以及总和错误但角相等的情况，专门检查先判断总和。

The official Junior test package is bundled with six input/output pairs; the `.in` and `.out` files are preserved unchanged. Independent boundary checks cover sums equal to and different from 180, all-equal angles, exactly one equal pair, and equal angles with an invalid sum to check that the sum is tested first.
