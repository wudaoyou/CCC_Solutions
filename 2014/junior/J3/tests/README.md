官方 Junior 测试包已随仓库提供，包含 5 组输入输出；这些 `.in` 和 `.out` 文件保持原样。独立核对枚举了单轮骰子的 36 种点数组合，并另外检查多轮混合胜负、平局和骰子点数 1 与 6；计算始终按较低点数者扣较高点数。

The official Junior test package is bundled with five input/output pairs; the `.in` and `.out` files are preserved unchanged. An independent check covered all 36 single-round roll pairs and additional mixed rounds with wins, ties, and rolls of 1 and 6. Each loss subtracts the higher roll from the player with the lower roll.
