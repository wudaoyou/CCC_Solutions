2014 J2 · Vote Count

2014 / junior / J2

官方题目PDFDMOJ

题目在问什么

统计 A 和 B 的票数，输出票数较多的歌手；票数相同则输出 Tie。

考查知识点

  • 计数：检查一串投票中的每个字符，统计某个符号出现多少次。
  • 互补数量：每票只能投给 A 或 B，因此 B 票数等于总票数减去 A 票数。
  • 比较大小：两个票数中较大的歌手获胜，数量相同时是平局。

一步一步想

  1. 读取总票数 V 和由 A、B 组成的投票字符串。
  2. 计算 A 出现的次数 a_votes；再用 V - a_votes 得到 B 的票数。
  3. 比较两个数量：A 多就输出 A，B 多就输出 B，相等就输出 Tie。

用例子走一遍

投票 ABBABA 中，A 出现 3 次。总票数是 6，所以 B 也有 6-3=3 票；两人票数相同，输出 Tie。

为什么这样做是对的

输入中的每一票都是 A 或 B，因此统计到的 A 票数加上 B 票数恰好等于 V。程序数出 A 后用 V 减去它，得到准确的 B 票数。随后比较两个准确数量，分别在 A 多、B 多或相等时输出对应结果，覆盖了所有可能。

运行时间与内存

若有 V 票，count 会查看投票字符串中的每个字符一次，所以时间是 O(V)。O(V) 表示工作量随票数线性增加；例如票数翻倍，字符检查次数也约翻倍。程序保存投票字符串，额外空间是 O(V)。

容易出错的地方

  • 题目保证投票字符串长度正好是 V，且每个字符都是 A 或 B。
  • 平局时必须输出 Tie，注意大小写。
  • 不要只判断 A 是否过半而漏掉 B 获胜和平局。

Python 3 解法

solution.py
import sys

total, votes = sys.stdin.read().split()
a_votes = votes.count("A")
b_votes = int(total) - a_votes

if a_votes > b_votes:
    print("A")
elif b_votes > a_votes:
    print("B")
else:
    print("Tie")

官方题目

官方题目原文为英文；图表和原版排版请看 PDF。

Problem statement (English)
Problem J2: Vote Count
Problem Description
A vote is held after singer A and singer B compete in the final round of a singing competition.
Your job is to count the votes and determine the outcome.

Input Specification
The input will be two lines. The first line will contain V (1 ≤ V ≤ 15), the total number of
votes. The second line of input will be a sequence of V characters, each of which will be A or B,
representing the votes for a particular singer.

Output Specification
The output will be one of three possibilities:

   • A, if there are more A votes than B votes;

   • B, if there are more B votes than A votes;

   • Tie, if there are an equal number of A votes and B votes.


Sample Input 1
6
ABBABB

Output for Sample Input 1
B

Sample Input 2
6
ABBABA

Output for Sample Input 2
Tie

Official problemPDFDMOJ

What are we asked to do?

Count the votes for A and B, print the singer with more votes, or print Tie when their counts are equal.

Knowledge and skills

  • Counting: inspect a string and count how many times a chosen symbol appears.
  • Complementary counts: every vote is for A or B, so the number of B votes is the total minus the number of A votes.
  • Comparison: the singer with the larger count wins; equal counts make a tie.

Think step by step

  1. Read the total number of votes V and the string containing the A and B votes.
  2. Count the occurrences of A as a_votes. Calculate the B count as V - a_votes.
  3. Compare the counts: print A if A has more, B if B has more, and Tie if they are equal.

Walk through an example

In ABBABA, A appears 3 times. The total is 6, so B has 6-3=3 votes as well. The counts match, so print Tie.

Why does this work?

Every input vote is either A or B, so the two counts add up to V. The program counts A and subtracts that count from V to obtain the exact number of B votes. It then compares the two exact counts and prints the required result for A winning, B winning, or a tie. These cases cover all possibilities.

Time and memory

For V votes, count checks each character in the vote string once, so the running time is O(V). O(V) means the work grows in proportion to the number of votes; doubling the votes roughly doubles the checks. The program stores the vote string, so its extra space is O(V).

Common mistakes

  • The statement guarantees that the vote string has exactly V characters and each is A or B.
  • For a tie, print Tie with this capitalization.
  • Do not check only whether A has a majority and forget B wins and ties.
