# 原代码归档 / Original code archive

`original-code/` 原样保留旧 `CCC/foo/`、`CCC/bin/` 和 `CCC/__init__.py`。
这些是历史练习，不作为新解法或正确性的依据。原有测试数据已迁入对应题目的 `tests/`；迁移时核对了全部 1,543 个原文件的内容，未丢失原文件字节。

`original-code/` preserves the former `CCC/foo/`, `CCC/bin/` and `CCC/__init__.py` unchanged.
These historical exercises are not the new reference solutions. Existing test data was moved into each problem's `tests/` folder. All 1,543 original files were checked during migration; their contents were preserved.

旧文件名存在错标，整理以官方试卷为准，例如：

- 2012 旧 `J5` 实际解的是 Senior S1；官方 Junior J5 与 Senior S4 是 A Coin Game。
- 2013 旧 `J3`/`J4` 文件对应题意与官方题号相反。
- 同题的 Junior/Senior 解法今后只在 Senior 目录维护。

Some old filenames do not match the official problem numbers. The official papers define the new layout, including the 2012 J5/S4 and 2013 J3/J4 corrections. Shared solutions will be maintained only in Senior.
