2015 J3 · Rövarspråket

2015 / junior / J3

官方题目PDFDMOJ

题目在问什么

把每个辅音扩展为三个字母：原辅音、字母表中最近的元音、以及后面的辅音；元音保持不变。

考查知识点

  • 元音和辅音：元音是 a、e、i、o、u；小写字母表中的其他字母都是辅音。
  • 字母表距离：比较字母在字母表中的位置来找最近元音。例如 d 离 e 一格，所以最近元音是 e。
  • 平局规则：若两个元音距离相同，选字母表中靠前的那个；例如 c 在 a 和 e 正中间，所以选 a。
  • 下一个辅音：从当前辅音继续向后找一个辅音；z 没有下一个字母，所以仍选 z。

一步一步想

  1. 按顺序读取单词里的每个字母。若它是元音，直接保留。
  2. 若它是辅音，从 a、e、i、o、u 中找字母表距离最小的元音。候选元音按字母顺序检查，只在距离更小时更新，因此相同距离会保留较早的元音。
  3. 把辅音本身、最近元音和下一个辅音依次加入结果；遇到 z 时第三个字母仍是 z。
  4. 连接所有结果并输出。

用例子走一遍

单词 joy 中，j 变成 jik：最近元音是 i，下一个辅音是 k；o 是元音，保持不变；y 变成 yuz。因此输出 jikoyuz。

为什么这样做是对的

程序从左到右处理每个输入字母。元音直接复制，符合规则。对辅音，它比较与五个元音的字母距离，并在距离相等时保留更早检查的元音；候选顺序 a、e、i、o、u 正好是字母表顺序，所以符合平局规则。程序再追加后一个辅音，且对 z 特别保留 z。每个输入字母都按规定转换一次，因此连接后的单词正确。

运行时间与内存

设输入单词长度为 L。每个字母最多检查固定的 5 个元音和 21 个辅音，因此工作量随 L 成正比，运行时间是 O(L)。O(L) 表示单词长度翻倍时，处理量也大约翻倍。结果最多有 3L 个字母，所以额外空间是 O(L)。

容易出错的地方

  • 元音原样保留；不要为元音添加两个字母。
  • c、g、l、r 等字母可能与两个元音等距，必须选字母表中较早的元音。
  • z 的下一个辅音仍是 z；其他辅音要跳过后续元音找到下一个辅音。

Python 3 解法

solution.py
word = input()
vowels = "aeiou"
consonants = "bcdfghjklmnpqrstvwxyz"
translated = []

for letter in word:
    if letter in vowels:
        translated.append(letter)
        continue

    closest = vowels[0]
    for vowel in vowels[1:]:
        if abs(ord(letter) - ord(vowel)) < abs(ord(letter) - ord(closest)):
            closest = vowel

    if letter == "z":
        next_consonant = "z"
    else:
        next_consonant = consonants[consonants.index(letter) + 1]
    translated.extend((letter, closest, next_consonant))

print("".join(translated))

Problem statement (English)
Problem J3: Rövarspråket
Problem Description
In Sweden, there is a simple child’s game similar to Pig Latin called Rövarspråket (Robbers Lan-
guage).
In the CCC version of Rövarspråket, every consonant is replaced by three letters, in the following
order:

   • the consonant itself;

   • the vowel closest to the consonant in the alphabet (e.g., if the consonant is d, then the closest
     vowel is e), with the rule that if the consonant falls exactly between two vowels, then the
     vowel closer to the start of the alphabet will be chosen (e.g., if the consonant is c, then the
     closest vowel is a);

   • the next consonant in the alphabet following the original consonant (e.g., if the consonant is
     d, then the next consonant is f) except if the original consonant is z, in which case the next
     consonant is z as well.

Vowels in the word remain the same. (Vowels are a, e, i, o, u and all other letters are consonants.)
Write a program that translates a word from English into Rövarspråket.

Input Specification
The input consists of one word entirely composed of lower-case letters. There will be at least one
letter and no more than 30 letters in this word.

Output Specification
Output the word as it would be translated into Rövarspråket on one line.

Sample Input 1
joy

Output for Sample Input 1
jikoyuz

Sample Input 2
ham

Output for Sample Input 2
hijamon

Official problemPDFDMOJ

What are we asked to do?

Expand each consonant into three letters: itself, the closest vowel in the alphabet, and the next consonant; leave vowels unchanged.

Knowledge and skills

  • Vowels and consonants: the vowels are a, e, i, o, and u; every other lowercase letter is a consonant.
  • Alphabet distance: compare letter positions to find the nearest vowel. For example, e is one alphabet step from d, so it is d's closest vowel.
  • Tie rule: if two vowels are equally close, choose the one earlier in the alphabet. For example, c is halfway between a and e, so choose a.
  • Next consonant: move forward to the next consonant after the original one; z stays z because no later letter exists.

Think step by step

  1. Process the word one letter at a time. Copy a vowel unchanged.
  2. For a consonant, find the vowel with the smallest alphabet distance among a, e, i, o, and u. Check vowels in alphabet order and update only for a smaller distance, so an equal-distance tie keeps the earlier vowel.
  3. Append the consonant, its closest vowel, and the next consonant in that order. For z, use z as the third letter.
  4. Join all pieces and print the translated word.

Walk through an example

In joy, j becomes jik: its closest vowel is i and its next consonant is k. The vowel o stays unchanged, and y becomes yuz. The result is jikoyuz.

Why does this work?

The program processes every input letter from left to right. A vowel is copied unchanged, as required. For a consonant, it compares alphabet distances to all five vowels; when distances tie, it keeps the first one checked. Since the vowels are checked in alphabet order a, e, i, o, u, this implements the tie rule. It then appends the next consonant, with the required special case for z. Thus every input letter is translated according to the statement, and joining the pieces gives the correct word.

Time and memory

Let L be the input length. Each letter checks at most five vowels and 21 consonants, both fixed-size lists, so the running time is O(L). O(L) means doubling the word length roughly doubles the work. The result has at most 3L letters, so extra space is O(L).

Common mistakes

  • Keep vowels unchanged; do not add two more letters after them.
  • Letters such as c, g, l, and r are equally close to two vowels; choose the earlier vowel in the alphabet.
  • The next consonant after z is z itself; for other consonants, skip over any vowels.
