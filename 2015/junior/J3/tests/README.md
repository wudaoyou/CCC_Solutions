The official Junior test package is bundled with five input/output pairs. An independent check translated the full lowercase alphabet to cover every consonant, all four equal-distance vowel choices (c, g, l, r), unchanged vowels, the special z rule, and the 30-character limit; the official `.in` and `.out` files remain unchanged.
