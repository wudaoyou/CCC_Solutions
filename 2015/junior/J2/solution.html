2015 J2 · Happy or Sad

2015 / junior / J2

官方题目PDFDMOJ

题目在问什么

统计消息里的快乐表情 :-) 和难过表情 :-(，根据两种表情的数量判断整体情绪。

考查知识点

  • 子字符串：子字符串是消息中连续的一小段字符；本题只统计完整的 :-) 和 :-(。
  • 计数：分别数出快乐表情和难过表情出现的次数。
  • 分类顺序：没有任何表情时输出 none；至少有一种时，数量相等才输出 unsure。

一步一步想

  1. 读取整行消息，保留其中的空格和标点。
  2. 统计完整的 :-) 出现次数 happy，以及 :-( 出现次数 sad。
  3. 若两种次数都是 0，输出 none；否则，次数相等就输出 unsure，happy 较多输出 happy，sad 较多输出 sad。

用例子走一遍

消息 `How are you :-) doing :-( today :-)?` 有两个快乐表情和一个难过表情，所以输出 happy。消息 `:)` 不含题目规定的完整表情，输出 none。

为什么这样做是对的

程序分别统计消息中两种指定的连续字符序列，因此得到快乐和难过表情的实际数量。如果两数都是 0，就符合“没有表情”的规则；否则相等代表有表情但数量打平，输出 unsure。两数不等时，较大的那一类就是较多的情绪，程序输出 happy 或 sad。因此每条消息都落入题目规定的一种结果。

运行时间与内存

设消息长度为 L。统计每种表情都要扫描消息一次，所以运行时间是 O(L)；O(L) 表示消息每增加一个字符，扫描工作也按比例增加。程序保存整行消息，额外空间是 O(L)，两个计数器只占固定空间。

容易出错的地方

  • 要匹配完整的三个字符；`:)` 不是题目定义的快乐表情。
  • 没有表情时必须输出 none；不能因为 0 等于 0 就输出 unsure。
  • 消息可能含有空格和其他标点，仍要读取整行。

Python 3 解法

solution.py
message = input()
happy = message.count(":-)")
sad = message.count(":-(")

if happy == 0 and sad == 0:
    print("none")
elif happy == sad:
    print("unsure")
elif happy > sad:
    print("happy")
else:
    print("sad")

官方题目

官方题目原文为英文；图表和原版排版请看 PDF。

Problem statement (English)
Problem J2: Happy or Sad
Problem Description
We often include emoticons in our text messages to indicate how we are feeling. The three con-
secutive characters :-) indicate a happy face and the three consecutive characters :-( indicate a
sad face. Write a program to determine the overall mood of a message.

Input Specification
There will be one line of input that contains between 1 and 255 characters.

Output Specification
The output is determined by the following rules:

   • If the input line does not contain any happy or sad emoticons, output none.

   • Otherwise, if the input line contains an equal number of happy and sad emoticons, output
     unsure.

   • Otherwise, if the input line contains more happy than sad emoticons, output happy.

   • Otherwise, if the input line contains more sad than happy emoticons, output sad.


Sample Input 1
How are you :-) doing :-( today :-)?

Output for Sample Input 1
happy

Sample Input 2
:)

Output for Sample Input 2
none

Sample Input 3
This:-(is str:-(:-(ange te:-)xt.

Output for Sample Input 3
sad

Official problemPDFDMOJ

What are we asked to do?

Count the happy :-) and sad :-( emoticons in a message, then use their counts to decide its overall mood.

Knowledge and skills

  • Substring: a substring is a consecutive piece of text; this problem counts only the full sequences :-) and :-(.
  • Counting: find the number of happy emoticons and the number of sad emoticons separately.
  • Decision order: print none when there are no emoticons; only use unsure for equal counts when at least one emoticon exists.

Think step by step

  1. Read the whole message, keeping its spaces and punctuation.
  2. Count the occurrences of :-) as happy and :-( as sad.
  3. If both counts are 0, print none. Otherwise, print unsure for equal counts, happy when happy is larger, and sad when sad is larger.

Walk through an example

The message `How are you :-) doing :-( today :-)?` has two happy emoticons and one sad emoticon, so print happy. The message `:)` has no complete emoticon from the problem, so print none.

Why does this work?

The program counts each of the two specified character sequences in the message, giving their actual totals. If both totals are 0, the no-emoticon rule applies. Otherwise, equal totals mean the emoticons tie, so it prints unsure. When the totals differ, the larger one identifies whether happy or sad appears more often. These cases match every output rule in the statement.

Time and memory

Let L be the message length. Counting each emoticon scans the message once, so the running time is O(L). O(L) means the amount of scanning grows in proportion to the number of characters. The program stores the input line, so extra space is O(L); the two counters use a fixed amount of space.

Common mistakes

  • Match all three characters; `:)` is not the happy emoticon defined in the problem.
  • With no emoticons, print none; do not treat 0 equal to 0 as unsure.
  • The message can contain spaces and other punctuation, so read the entire line.
