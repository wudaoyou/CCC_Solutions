官方 Junior 测试包已随仓库提供，包含 8 组输入输出。独立检查用逐个起点扫描完整的三字符表情，覆盖无表情、仅一种表情、平局、相邻表情和 255 字符上限；官方 `.in` 和 `.out` 文件保持原样。

The official Junior test package is bundled with eight input/output pairs. An independent check scanned every possible starting position for the full three-character emoticons and covered no emoticons, either mood alone, ties, adjacent emoticons, and the 255-character limit; the official `.in` and `.out` files remain unchanged.
