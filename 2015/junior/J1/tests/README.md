官方 Junior 测试包已随仓库提供，包含 9 组输入输出。独立检查枚举了 2015 年的全部有效日期，共 365 天，并把程序结果和日期与 2 月 18 日的先后关系逐一比较；官方 `.in` 和 `.out` 文件保持原样。

The official Junior test package is bundled with nine input/output pairs. An independent check enumerated all 365 valid dates in 2015 and compared each result with its order relative to February 18; the official `.in` and `.out` files remain unchanged.
