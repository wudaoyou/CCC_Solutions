2013 J2 · Rotating letters

2013 / junior / J2

官方题目PDFDMOJ

题目在问什么

检查单词中的每个大写字母是否都属于旋转 180 度后外形不变的字母集合；全部符合就输出 YES。

考查知识点

  • 集合：集合是一组允许的值；本题允许的字母只有 I、O、S、H、Z、X、N。
  • 成员检查：判断一个字母是否在集合中，例如 I 在集合里，A 不在。
  • 逐项检查：单词只有在每个字母都符合条件时才有效；发现一个不允许的字母就可以回答 NO。

一步一步想

  1. 读取一个没有空格的大写单词。
  2. 把题目列出的七个字母记为允许集合。
  3. 逐个检查单词里的字母。如果每个字母都在允许集合中，输出 YES；否则输出 NO。

用例子走一遍

SHINS 的字母 S、H、I、N、S 都在允许集合中，因此可以用于标牌，输出 YES。NOISE 含有 E，而 E 不在集合中，所以输出 NO。

为什么这样做是对的

题目规定单词可用，当且仅当其中每个字母都属于 I、O、S、H、Z、X、N。程序对单词中的每个字母检查集合成员关系；只有所有检查都通过时才输出 YES。若有字母不在集合中，检查结果为假并输出 NO，正好符合题目规则。

运行时间与内存

若单词长度为 n，程序检查每个字母一次，因此运行时间是 O(n)。O(n) 表示单词每多一个字母，最多多做一次检查。允许集合固定只有七个字母；除了保存输入单词外，额外空间是 O(1)。

容易出错的地方

  • 七个允许字母必须完整：I、O、S、H、Z、X、N。
  • 只要有一个字母不在集合中，就必须输出 NO；不要求单词是回文或重新排列。
  • 输出大写的 YES 或 NO，不要输出解释文字。

Python 3 解法

solution.py
import sys

word = sys.stdin.readline().strip()
rotatable = set("IOSHZXN")
print("YES" if all(letter in rotatable for letter in word) else "NO")

Problem statement (English)
Problem J2: Rotating letters
Problem Description
An artist wants to construct a sign whose letters will rotate freely in the breeze. In order to do this,
she must only use letters that are not changed by rotation of 180 degrees: I, O, S, H, Z, X, and N.
Write a program that reads a word and determines whether the word can be used on the sign.

Input Specification
The input will consist of one word, all in uppercase letters, with no spaces. The maximum length
of the word will be 30 letters, and the word will have at least one letter in it.

Output Specification
Output YES if the input word can be used on the sign; otherwise, output NO.
Sample Input 1
SHINS
Output for Sample Input 1
YES
Sample Input 2
NOISE
Output for Sample Input 2
NO

Official problemPDFDMOJ

What are we asked to do?

Check whether every uppercase letter in the word belongs to the set of letters unchanged by a 180-degree rotation; print YES only if they all do.

Knowledge and skills

  • A set: a set is a collection of allowed values. The allowed letters here are I, O, S, H, Z, X, and N.
  • Membership: check whether a letter belongs to the set; for example, I is in it and A is not.
  • Checking every item: a word is valid only when every letter passes; one disallowed letter is enough to answer NO.

Think step by step

  1. Read one uppercase word with no spaces.
  2. Store the seven letters from the statement as the allowed set.
  3. Check each letter in the word. Print YES if every letter is in the set; otherwise print NO.

Walk through an example

Every letter in SHINS—S, H, I, N, and S—is in the allowed set, so print YES. NOISE contains E, which is not in the set, so print NO.

Why does this work?

The statement says a word can be used exactly when each of its letters belongs to I, O, S, H, Z, X, or N. The program checks set membership for every letter and prints YES only when all checks pass. If any letter is outside the set, it prints NO, as required.

Time and memory

For a word of length n, the program checks each letter once, so the running time is O(n). O(n) means one more letter adds at most one more check. The allowed set always has seven letters, so extra space beyond the stored input word is O(1).

Common mistakes

  • Include all seven allowed letters: I, O, S, H, Z, X, and N.
  • One letter outside the set means NO; the word does not need to be a palindrome or rearranged.
  • Print uppercase YES or NO with no explanation text.
