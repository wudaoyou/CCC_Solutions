官方题目PDFDMOJ

题目在问什么

读取多组温度序列，找出连续温差的最短循环长度；输入 0 时结束。

考查知识点

  • 差分：用后一个温度减前一个温度，例如 3 到 5 的温差为 +2。
  • 枚举：按 1、2、3……的顺序尝试所有可能的周期长度。
  • 取余：i % p 表示 i 除以 p 的余数，用它找第 i 项在循环中的位置。

一步一步想

  1. 计算相邻温度之差，把上升和下降都保留为有符号整数。
  2. 依次尝试长度为 1 到温差数量的周期。前 p 个温差定义长度为 p 的循环。
  3. 从第 p 项开始，检查 changes[i] 是否等于 changes[i % p]。例如 p=3 时，下标 3、4、5 对应循环中的下标 0、1、2。第一个全部通过的 p 就是答案。
  4. 如果只有一个温度，就没有温差，输出 0。

用例子走一遍

温度 3, 4, 6, 4, 5, 7, 5 的温差是 +1, +2, -2, +1, +2, -2，最短循环长度为 3。另一个序列 0, -2, 3, 1, 6, 4 的温差是 -2, +5, -2, +5, -2；长度 2 的循环重复两次后，末尾再出现一个匹配的部分循环。

为什么这样做是对的

对候选长度 p，前 p 个温差定义循环。程序逐个检查其余位置 i 是否等于 changes[i % p]，因此通过检查就说明这个循环覆盖了完整序列，包括末尾可能不完整的一次重复。候选长度按从小到大检查，所以第一个通过的长度最短；温差总数本身一定可行。没有温差时答案为 0。

运行时间与内存

一组数据有 m=n−1 个温差。最多尝试 m 个周期，每个至多检查 m 项，时间为 O(m²)，意思是检查次数最多按 m 的平方增长。多组数据分别计算，再把工作量相加。代码一次读入所有 U 个输入整数，并保存 T 个答案，因此整个程序的空间为 O(U+T)；当前这一组的温差列表另需 O(m) 空间，已包含在这个总量中。题目每组最多 20 个温度，枚举足够快。

容易出错的地方

  • 比较的是相邻温度之差，不是温度本身。
  • 下降对应负差值，不能只记录变化的绝对值。
  • 最后一次重复可以不完整，但其中已有的每一项都必须匹配周期。
  • 单个温度产生零个温差，答案是 0。

Python 3 解法

solution.py
import sys


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    answers = []
    pos = 0

    while pos < len(data):
        n = data[pos]
        pos += 1
        if n == 0:
            break

        temperatures = data[pos:pos + n]
        pos += n
        changes = [b - a for a, b in zip(temperatures, temperatures[1:])]

        if not changes:
            answers.append("0")
            continue

        for period in range(1, len(changes) + 1):
            if all(changes[i] == changes[i % period] for i in range(period, len(changes))):
                answers.append(str(period))
                break

    sys.stdout.write("\n".join(answers))
    if answers:
        sys.stdout.write("\n")


if __name__ == "__main__":
    main()

Problem statement (English)
Problem J4: Global Warming
Problem Description
Your task is to help scientists predict the trend of the global warming. One of the hypotheses they
are considering is that over long periods of time, the average temperature follows certain cycles,
but each time the cycle starts from a higher temperature level. The temperatures are measured over
five-year averages, and expressed in tenths of a degree.
For example, if the following five-year averages are observed:
                                           3, 4, 6, 4, 5, 7, 5
then we can calculate that the temperature changes first 1 tenth up, then 2 up, then 2 down, 1 up,
2 up, and 2 down. There is a cycle of changes of length three which covers all of the temperature
differences: (+1, +2, −2). In other words, if we look at the differences starting at the first position,
there is a cycle of length three of the form (+1, +2, −2) followed by another cycle of length three
of exactly the same form.
By way of another example, suppose the following average temperatures are observed:
                                               3, 4, 6, 7.
In this case, there is a difference of one up, two up, then one up. We would consider the shortest
cycle to be length two in this case: the cycle (+1, +2). Notice that this cycle occurs once, followed
by one truncated occurrence of exactly the same cycle.
Your task is to find the shortest such cycle from a given sequence of temperatures.

Input Specification
The input consists of a number of test cases. Each test case starts with the number n (1 ≤ n ≤ 20),
representing the number of temperatures in a sequence, followed by the sequence of n temper-
atures. You may assume that each temperature input is an integer in the range −1000...1000
inclusive. The numbers are separated by a single space. The last test case is indicated by a zero
and should produce no output.

Output Specification
For each test case, produce the length of the shortest temperature cycle. The cycle always exists,
since the whole sequence could be treated as one long cycle.

 Sample Input                Output for this test case
 7 3 4 6 4 5 7 5             3
 3 1 3 5                     1
 3 1 4 5                     2
 4 3 4 6 7                   2
 0



                                                   8

Official problemPDFDMOJ

What are we asked to do?

For each temperature sequence, find the shortest repeating cycle of consecutive changes. Input ends with 0.

Knowledge and skills

  • Differences: subtract the previous temperature from the next one; a change from 3 to 5 is +2.
  • Enumeration: try each possible cycle length in order, starting with 1, 2, 3, and so on.
  • Remainder: i % p is the remainder when i is divided by p; it gives position i within the repeating cycle.

Think step by step

  1. Compute each change between adjacent temperatures, keeping increases and decreases as signed integers.
  2. Try cycle lengths p from 1 through the number of changes. The first p changes define a cycle of length p.
  3. Starting at position p, check changes[i] against changes[i % p]. For p=3, positions 3, 4, 5 correspond to cycle positions 0, 1, 2. The first p that passes every check is the answer.
  4. With one temperature there are no changes, so output 0.

Walk through an example

For temperatures 3, 4, 6, 4, 5, 7, 5, the changes are +1, +2, -2, +1, +2, -2, so the shortest cycle has length 3. For 0, -2, 3, 1, 6, 4, the changes are -2, +5, -2, +5, -2: a length-2 cycle repeats twice and ends with one matching part of a third repetition.

Why does this work?

For a candidate length p, the first p changes define the cycle. The program checks each later position i against changes[i % p], so a passing candidate covers the whole sequence, including any truncated final repetition. Candidates are checked in increasing order, making the first passing length shortest; the full change sequence always works. With no changes, the answer is 0.

Time and memory

One case has m=n−1 changes. There are at most m candidate lengths, each checking at most m entries, so time is O(m²): the number of checks grows at most like the square of m. Add the work for all cases. This code reads all U input integers at once and stores T answers, so total program space is O(U+T). The current list of m changes fits within that bound. With at most 20 temperatures per case, enumeration is easily fast enough.

Common mistakes

  • Compare consecutive temperature changes, not the temperatures themselves.
  • Keep changes signed so a decrease remains negative.
  • The final repetition may be truncated, but every change it contains must match the cycle.
  • One temperature gives zero changes and an answer of 0.
