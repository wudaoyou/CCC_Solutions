2011 J3 · Sumac Sequences

2011 / junior / J3

官方题目PDFDMOJ

题目在问什么

从给定的前两项开始，每次用前一项减去当前项生成下一项；数列在前一项小于当前项时结束。输出包含首尾在内的项数。

考查知识点

  • 状态模拟：只保存当前相邻的两项，就能计算下一项。
  • 循环条件：只有前一项不小于当前项时，才继续生成下一项。
  • 计数器：每生成一项就把长度加一。

一步一步想

  1. 读取 t1 和 t2，并把长度设为 2，因为这两项已经属于数列。
  2. 只要 first 大于或等于 second，就计算 next_term = first - second。此时相减不会得到负数。
  3. 把相邻两项向前移动：first 变成旧的 second，second 变成新项；长度加一。
  4. 当 first 小于 second 时，末尾两项已经满足停止条件，不再生成新项，输出长度。

用例子走一遍

输入 120 和 71：下一项依次是 49、22、27。生成 27 后，前一项 22 小于当前项 27，所以数列在此结束，长度为 5。

为什么这样做是对的

每次循环都按定义把 first-second 作为下一项，并将这项和它前面的项作为新的相邻两项，因此所有生成的项都与 Sumac 规则一致。循环只在 first 大于或等于 second 时继续；这等价于尚未满足“前一项小于当前项”的停止条件。离开循环时，末尾两项满足题目条件，长度计入了最初两项和每个新生成项。

运行时间与内存

若数列共有 k 项，循环每次只生成一项，因此运行时间为 O(k)，也就是每个数列项处理一次。程序只保存两项和长度，额外空间为 O(1)，即固定数量的值。

容易出错的地方

  • 相减顺序是前一项减当前项，不是反过来。
  • 相邻两项相等时还要继续；只有前一项严格小于当前项才停止。
  • 长度从 2 开始，因为输入的 t1 和 t2 已经是前两项。

Python 3 解法

solution.py
import sys


first, second = map(int, sys.stdin.read().split())
length = 2

while first >= second:
    next_term = first - second
    first, second = second, next_term
    length += 1

print(length)

Problem statement (English)
Problem J3: Sumac Sequences
Problem Description
In a sumac sequence, t1 , t2 , .., tm , each term is an integer greater than or equal 0. Also, each term,
starting with the third, is the difference of the preceding two terms (that is, tn+2 = tn − tn+1 for
n ≥ 1). The sequence terminates at tm if tm−1 < tm .
For example, if we have 120 and 71, then the sumac sequence generated is as follows:

                                          120, 71, 49, 22, 27.

This is a sumac sequence of length 5.

Input Specification
The input will be two positive numbers t1 and t2 , with 0 < t2 < t1 < 10000.

Output Specification
The output will be the length of the sumac sequence given by the starting numbers t1 and t2 .

Sample Input
120
71

Output for Sample Input
5

Official problemPDFDMOJ

What are we asked to do?

Start with the two given terms. Each new term is the previous term minus the current term. The sequence ends when the previous term is smaller than the current term. Print the number of terms, including both ends.

Knowledge and skills

  • State simulation: keeping the latest two terms is enough to make the next one.
  • Loop condition: make another term only while the previous term is at least the current term.
  • Counting: increase the length once for every generated term.

Think step by step

  1. Read t1 and t2, and set the length to 2 because both are already terms in the sequence.
  2. While first is greater than or equal to second, calculate next_term = first - second. This subtraction is nonnegative under the loop condition.
  3. Move the pair forward: first becomes the old second, and second becomes the new term. Increase the length by one.
  4. When first is less than second, the final two terms satisfy the stopping rule. Generate nothing more and print the length.

Walk through an example

For input 120 and 71, the next terms are 49, 22, and 27. After generating 27, the previous term 22 is smaller than 27, so the sequence stops with length 5.

Why does this work?

Each loop computes first-second as the next term required by the definition, then makes the adjacent pair the new current state. Thus every generated term follows the Sumac rule. The loop continues exactly while first is at least second, which means the stopping condition that the previous term is smaller than the current term has not yet been met. When the loop ends, the final pair meets that condition, and the counter includes the first two terms plus every generated term.

Time and memory

If the sequence has k terms, the loop generates one term per iteration, so the running time is O(k): each term is processed once. The program stores only two terms and a counter, so extra space is O(1), meaning a fixed number of values.

Common mistakes

  • Subtract the current term from the previous term, in that order.
  • Equal adjacent terms do not stop the sequence; it stops only when the previous term is strictly smaller.
  • Start the length at 2 because the input values t1 and t2 are already the first two terms.
